# CCFOLIA 导入功能来源说明

## English

SealChat's CCFOLIA room import feature was independently implemented based on Room Data exported by users themselves and publicly observable usage patterns. It does not contain CCFOLIA source code or official assets.

All related test fixtures use synthetic data and do not contain test data copied from CCFOLIA products, repositories, or official resources.

Users should only import content they have the right to copy, transform, and use in SealChat.

## 中文

SealChat 的 CCFOLIA 房间导入功能基于用户自行导出的 Room Data 与公开可观察的使用方式独立实现，不包含 CCFOLIA 源代码或官方素材。

相关测试 fixture 均使用人工合成数据，不包含从 CCFOLIA 产品、仓库或官方资源中复制的测试数据。

用户只应导入自己有权复制、转换和在 SealChat 中使用的内容。

## 日本語

SealChat の CCFOLIA ルームインポート機能は、ユーザー自身がエクスポートした Room Data と公開されている利用方法をもとに、独立して実装されています。CCFOLIA のソースコードや公式素材は含まれていません。

関連するテスト fixture はすべて人工的に作成したデータを使用しており、CCFOLIA の製品、リポジトリ、公式リソースからコピーしたテストデータは含まれていません。

ユーザーは、自身が複製・変換し、SealChat 上で利用する権利を有するコンテンツのみをインポートしてください。

## 한국어

SealChat의 CCFOLIA 방 가져오기 기능은 사용자가 직접 내보낸 Room Data와 공개적으로 확인 가능한 사용 방식을 바탕으로 독립적으로 구현되었습니다. CCFOLIA의 소스 코드나 공식 자산은 포함하지 않습니다.

관련 테스트 fixture는 모두 인위적으로 생성한 데이터를 사용하며, CCFOLIA 제품, 저장소 또는 공식 리소스에서 복사한 테스트 데이터를 포함하지 않습니다.

사용자는 자신이 복사, 변환 및 SealChat에서 사용할 권리가 있는 콘텐츠만 가져와야 합니다.
